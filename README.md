# CampusLab - Frontend

## 📝 Descripción del Proyecto

Este repositorio contiene el **Frontend** de **CampusLab**, una plataforma unificada diseñada para la reserva de laboratorios y equipos académicos en una red de instituciones de educación superior[cite: 3].

Este componente provee la interfaz gráfica para que los distintos usuarios interactúen con el sistema y se encarga de gestionar el login corporativo, así como la autorización basada en roles (Admin, Operador del dominio, Cliente del dominio)[cite: 3].

## 🚀 Tecnologías a usar

Según las definiciones de la arquitectura del proyecto, el frontend está construido con las siguientes tecnologías:

- **Angular:** Framework principal para la construcción de la interfaz de usuario (Single Page Application)[cite: 3].
- **MSAL (Microsoft Authentication Library):** Utilizado para integrar la autenticación y proteger las rutas mediante Azure AD (IDaaS)[cite: 3].
- **Azure AD:** Proveedor de identidad para el login corporativo mediante el botón «Iniciar sesión con Microsoft»[cite: 3].
